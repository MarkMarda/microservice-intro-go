# Microservices with go

## Run proyect
1- Use de Makefile to run. The file is inside project and here you call the Makefile.

2- If you need insert data in the database use the file auth-users, inside of auth-service

3- Commands:
```bash
## For docker compose
make up_build

## To start front-end
make start
```
See de Makefile to other commands
